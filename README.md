The motto (91 characters):

> Ship first, apologize in the changelog, and never let a perfect plan outrank a working one.

## Run it

```sh
node main.ts
```

The program writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), prints it, and self-checks the file (1–200 chars, single line, non-blank) before exiting.
